Install in 3 steps

  1. Download the installer

    Press “Download for Windows” above: the GitHub releases page opens. Under “Assets” of the latest release, get Aura-Setup-X.Y.Z.exe.

  2. Open it (and don't worry about the warning)

    Windows may show a blue screen saying “Windows protected your PC”. That's normal: Aura is a new, independent app and doesn't have the paid signature Microsoft recognises yet. It does not mean it's dangerous. Click More info, then Run anyway.

    If you'd rather check for yourself, all the code is public on GitHub.

  3. Enjoy

    Pick a scene and the widgets you like. That's it: your desktop is alive.

FAQ

Is it really free?

Yes. No ads, no paid tier, no account. If you like it you can support the project (below).

Does it use a lot of CPU or battery?

No. When a window covers the desktop the wallpaper pauses and uses about 0.3% CPU.

Which Windows versions are supported?

Windows 10 and Windows 11.

Why do I see a SmartScreen warning?

Because the installer isn't signed with a paid certificate and Windows is wary of little-known apps. Click “More info”, then “Run anyway”.

Windows 11 blocks Aura (Smart App Control)

If Smart App Control is on in your Windows 11, it blocks any program without a digital signature and, unlike SmartScreen, offers no “Run anyway”. Aura is not signed yet, so it may be blocked. You have two options: wait until we sign the installer (it is pending) or turn Smart App Control off in Windows Security › App & browser control. Note: once turned off, Windows won't let you turn it back on without reinstalling. If you'd rather not turn it off, don't install Aura yet. You can verify the download with the SHA256SUMS.txt file of each release.

How do I uninstall it?

From Windows Settings, Apps, like any other program.

Does it collect my data?

The app doesn't: there is no telemetry of any kind. This website only counts anonymous visits (see “Website statistics”).
